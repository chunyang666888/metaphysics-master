# 卜筮实战断法规则库（梅花易数 / 文王纳甲六爻 / 道传小六壬）

本文件规定脚本排盘之后的大模型断盘顺序，确保「先核盘、再理链、后定应期」，禁止脱离盘面自由编造。（大六壬专项法则见 `references/daliuren-rules.md`。）

## 一、梅花易数实战断法（依《梅花易数》原典）

1. **卦义先行**：先读本卦、互卦、变卦的《周易》卦名与象意（参见 `references/yijing64-wuyun.md`）。
2. **明确体用**：无动爻之经卦为**体卦**（代表求测人、我方）；含动爻之经卦为**用卦**（代表所测之事、对方）。
3. **拆解三阶段**：本卦（体用）看当下现状与近期互动（近应）；互卦（上下互）看中间过程与隐性卡点（中程）；变卦（体与变卦之用）看最终走势与结局（后势）。
4. **五行生克叠加四时旺衰**：
   - 基本关系：用生体（大吉进益）、体用比和（顺遂）、体克用（可成但费力）、体生用（耗泄破财）、用克体（凶受制阻）。
   - 必须叠加月令旺衰（春木旺、夏火旺、秋金旺、冬水旺、辰戌丑未土旺）：体卦宜旺相，若体囚用旺，即使体克用亦主反折受损。
5. **应期推导**：静中起卦按先天卦数之和定日/周/月；动中起卦以生体/克用之五行所值年月日起应。

## 二、文王纳甲六爻实战断法（依《增删卜易》《卜筮正宗》）

1. **输入契约**：严格自下而上（初爻到上爻）。硬币换算：3字=9(老阳动)，2字1背=8(少阴静)，1字2背=7(少阳静)，3背=6(老阴动)。
2. **审题取用神**：
   - **父母**：文书、合同、考试成绩、房产车辆、长辈、劳碌。
   - **官鬼**：工作职位、领导、官方、考试名次、女测夫、疾病、官司阻力。
   - **妻财**：金钱利润、薪资、货物、男测妻、实际资源。
   - **子孙**：解忧福神、创意技术、医药、投资回报源头、克官鬼（测官/职忌子孙动，测病/官司喜子孙动）。
   - **兄弟**：竞争对手、同行、同事、朋友、劫财破耗（求财最忌兄弟动）。
3. **断盘六步法**：
   - **看用神旺衰**：月建司权、日辰主宰；辨月破、日冲（旺相为暗动，休囚为日破）、旬空（旺动为假空，休囚受克为真空）。
   - **看世应结构**：世为己、应为彼/环境；世应生合易成，冲克主分歧。
   - **看动变作用链**：静爻不克动爻；变爻只管回头生克本位动爻；辨化进神（力量递增）、化退神（力量衰减）、回头克（根基被毁）。
   - **看伏神飞神**：用神不上卦时从本宫首卦找伏神，看日月生扶或飞神空破/生伏以判出伏条件。
   - **看特殊卦象**：六冲主速主散、六合主缓主成、反吟主反复、伏吟主呻吟停滞。
   - **条件性应期链**：严格按「当前病处 -> 解除条件 -> 应期窗口」推导（空待出空/冲空，合待冲开，墓待冲墓，破待实破/逢合，静待逢值/冲动）。

## 三、道传小六壬速断法则

六宫：**大安(木)、留连(土)、速喜(火)、赤口(金)、小吉(水)、空亡(土)**。
三宫对应「初阶(一宫) -> 中程(二宫) -> 结局(三宫)」，以第三宫为最终落脚点，并看二、三宫五行生克：
- 大安（稳重慢成）、留连（拖延反复）、速喜（喜讯快成）、赤口（口舌是非惊恐）、小吉（贵人稳妥有成）、空亡（落空虚耗，唯避灾反吉）。
